Project Summary & Architecture

This machine learning system predicts Titanic passenger survival using supervised binary classification. Built end-to-end with Python, pandas, scikit-learn, and deployed using a lightweight Flask web service.

1. Data Cleaning

Missing age imputed with median (28 yrs); missing embarkation port imputed with mode ('S'). Leaking/redundant attributes removed.

2. Model Selection

Trained Logistic Regression (79.89%) and Random Forest (82.68%). Random Forest won due to superior non-linear feature interaction capture.

3. Production Inference

Serialized model into model.joblib with real-time JSON prediction API and interactive web interface.
